\# Rollback (voltar versão em 30 segundos)



\## Quando usar

\- Se algum update quebrar YouTube/Drive

\- Se o BAT parar de funcionar

\- Se der erro estranho (IndentationError / WinError)



\## Como voltar para uma versão anterior

1\) Entre na pasta releases e escolha uma versão:

C:\\transcritor\\releases\\



2\) Copie app.py e TRANSCRITOR.bat dessa versão para a raiz:

\- C:\\transcritor\\app.py

\- C:\\transcritor\\TRANSCRITOR.bat



3\) Teste rodando o BAT.



\## Regra de ouro

Não altere o stable direto.

Teste primeiro em:

C:\\transcritor\_dev
